# אח כללי – תוכנת דיווח מצב מחלקות ונוכחות צוות

תוכנה לאחים/אחיות כלליים: בכל משמרת (בוקר / ערב / לילה) האח הכללי נכנס מהטאבלט עם שם המשתמש שלו, בוחר את העמדה שלו (אח כללי 1, 2, 3...), ורואה את המחלקות שבאחריותו. לכל מחלקה הוא ממלא:

1. **מטופלים**: כמה מטופלים יש במחלקה
2. **צוות**: כמה אנשי צוות יש במשמרת, ואם מישהו לא הגיע (פאנצ'ר) גם שם, סיבה (מחלה, מחלת ילד, לא הודיע...) והאם נמצא מחליף. יש גם מקום לדיווח חופשי על הצוות.
3. **חריגים במטופלים**: טקסט חופשי. אם אין חריגים, משאירים ריק.

כל הדיווחים נשמרים לצמיתות, ואפשר להפיק מהם **דוחות** לכל טווח תאריכים, משמרת, מחלקה או אח כללי. את הדוחות אפשר להדפיס או לשמור כ-PDF, וגם לייצא לאקסל.

---

## דרישות

- מחשב אחד ברשת (שרת או עמדה קבועה שדולקת תמיד) עם **Python 3.8 ומעלה**. אין צורך בהתקנת ספריות נוספות.
  להורדה: https://www.python.org/downloads/ (בהתקנה יש לסמן "Add python.exe to PATH")
- טאבלטים או מחשבים עם דפדפן (Chrome, Edge או Safari) באותה רשת.

## התקנה בתיקיית רשת

1. מעתיקים את כל התיקייה `nurse-supervisor` לתיקיית הרשת, למשל `\\server\share\אח-כללי`.
2. במחשב שישמש כשרת, לוחצים פעמיים על **`start.bat`**. ייפתח חלון שמציג את הכתובות, למשל:
   ```
   במחשב זה:   http://localhost:8080
   בטאבלטים:   http://10.0.0.25:8080
   ```
3. בטאבלטים פותחים את הכתובת שמופיעה בשורה "בטאבלטים". מומלץ להוסיף אותה ל**מסך הבית** כדי שתיפתח כמו אפליקציה.
4. נכנסים עם המשתמש **`admin`** והסיסמה **`admin`**. בכניסה הראשונה המערכת מחייבת להחליף את הסיסמה.

> **חשוב:** את `start.bat` מפעילים **במחשב אחד בלבד**, וכל הטאבלטים מתחברים אליו. החלון צריך להישאר פתוח, ואפשר למזער אותו.
> כדי שהשרת יעלה אוטומטית אחרי הפעלה מחדש, מוסיפים קיצור דרך ל-`start.bat` לתיקיית ה-Startup של Windows (`Win+R` ← `shell:startup`), או מגדירים משימה ב-Task Scheduler.
> ייתכן שיהיה צורך לפתוח את פורט 8080 בחומת האש של Windows (Windows Firewall).

### אפשרויות הפעלה

```
start.bat --port 9000                         # פורט אחר
start.bat --data "\\server\share\nurse-data"  # תיקיית נתונים במיקום אחר
```

## הגדרות (מנהל מערכת בלבד)

| לשונית | מה מגדירים |
|---|---|
| **שיבוץ מחלקות** | לכל מחלקה ולכל משמרת: איזה אח כללי אחראי עליה. מתחת לטבלה מוצגת חלוקת המחלקות לפי אח כללי. |
| **מחלקות** | שם, פעילה/לא פעילה |
| **אחים כלליים** | העמדות: אח כללי 1, 2, 3... (אפשר להוסיף ולשנות שמות) |
| **משמרות** | שמות ושעות המשמרות. לפי השעות נקבעת המשמרת הנוכחית. |
| **סיבות היעדרות** | הסיבות שמוצגות ככפתורים כשמדווחים על איש צוות שלא הגיע |
| **כללי** | שם המוסד, וחלון העריכה: כמה שעות אחרי סוף המשמרת אח כללי עוד יכול לתקן את הדיווח |
| **משתמשים** | הוספה, עריכה והשבתה של משתמשים, איפוס סיסמה, הרשאת מנהל |

## הרשאות

- **אח/ות כללי/ת**: ממלא/ת וצופה בדיווחים ומפיק/ה דוחות. אפשר לערוך דיווח עד מספר השעות שהוגדר אחרי סוף המשמרת.
- **מנהל מערכת**: כל הנ"ל, וגם הגדרות, משתמשים, עריכה ומחיקה של דיווחים ישנים.

## איפה נשמרים הנתונים

הכול נשמר בתיקייה `data` שליד התוכנה, בקבצי טקסט (JSON) שקל לגבות:

```
data/
  config.json              הגדרות (מחלקות, שיבוץ, משמרות...)
  users.json               משתמשים (הסיסמאות שמורות מוצפנות, hash)
  reports/2026/2026-11-09.json   כל הדיווחים של יום מסוים
  audit/2026-11.log        יומן פעולות: מי שמר, שינה או מחק, ומתי
  backups/                 גיבוי אוטומטי של ההגדרות לפני כל שינוי
```

- משמרת לילה שחוצה את חצות נשמרת תחת התאריך שבו היא **התחילה**.
- אם שני אחים עורכים את אותה מחלקה בו זמנית, המערכת מזהירה ולא דורסת את השינוי של השני.
- **גיבוי:** מספיק לגבות את תיקיית `data`.
