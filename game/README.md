# המשמרת — מסע קליני בגריאטריה

משחק RPG בסגנון GBA / Gen‑3, שנבנה על המבנה והשפה הגרפית של **בופי מן RPG** (מסך נוף, HUD עליון, תיבת משימה זהובה, קרבות עם לוחיות וגריד פקודות, חלונות בסגנון v57, פתיח Mae Studio), עם כל התוכן הקליני של Clinical Mastery v2.1.

## מטרת המשחק: ליבת המומחיות

המשחק בוחן ומבסס את הידע שמצופה מ**אח/ות מומחה/ית קליני/ת בגריאטריה** בארבעה תחומי ליבה:

| תחום | מה נבחן |
|---|---|
| 🫀 קרדיולוגיה | HF, AF ונוגדי קרישה, ACS בהסתמנות לא טיפוסית, הפרעות קצב, AS, לחץ דם ואורתוסטזיס |
| 🧓 גרונטולוגיה | פיזיולוגיה של הזדקנות, שבריריות (Fried, CFS) וסרקופניה, CGA, הסתמנות לא טיפוסית, ASB, עור ותזונה, התעללות והזנחה |
| 🧠 נוירולוגיה | דליריום (4AT, HELP), שבץ ו-TIA, פרקינסון, BPSD, חבלת ראש, NPH ודיכאון |
| 💊 פרמקולוגיה | PK/PD בזקנה, Beers ו-STOPP/START, עומס אנטיכולינרגי, Cockcroft-Gault ומינון DOAC, סרוטונין, מפל מרשמים, deprescribing |

- כל אירוע ממופה לתחום ליבה אחד או יותר (`js/core.js`). נוספו 15 אירועים ברמת מומחה (AS, ACS לא טיפוסי, AF ונפילות, פרקינסון, BPSD, TIA, עומס אנטיכולינרגי, תסמונת סרוטונינית, מינון apixaban, benzodiazepines, CFS, ASB, דיכאון ואובדנות, הזנחה, ריתוק למיטה).
- **49 בדיקות ידע** עם הסבר ומקור. הן מופיעות בקריאות ביפר, בקרבות עם מאמנים, מול היריב, בתרגול ממוקד ובמועצה. בדיקה שנכשלה חוזרת מוקדם יותר (חזרה מרווחת), ויש הטיה לטובת התחום החלש ביותר.
- **🎓 ליבת המומחיות** בתפריט: אחוז שליטה בכל תחום (חצי מקרים קליניים, חצי בדיקות ידע), זיהוי התחום החלש ותרגול ממוקד מול בוחן/ת.
- **מועצת המומחים**: כל שופט/ת בוחן/ת תחום ליבה אחד (קרדיולוגיה, נוירולוגיה, פרמקולוגיה, גרונטולוגיה), והיו״רית בוחנת את כולם.

## מבוסס מחקר וידע קליני

- **כל אחד מ-73 האירועים** מקושר להנחיה הקלינית שעליה הוא מבוסס, עם “מה אומרות ההנחיות”: נקודה קונקרטית מתוך ההנחיה (ספים, מינונים, קריטריונים) שמוצגת בסיכום האירוע, ביומן ובביקור הגדול. בין המקורות: AGS Beers 2023, STOPP/START v3, NICE (Delirium, Head injury NG232, Hip fracture), KDIGO (AKI, CKD 2024, Anemia 2026), UKKA Hyperkalaemia, ADA 2025, ADA/EASD Hyperglycemic crises 2024, Surviving Sepsis 2021, AHA (Stroke, ALS 2020, HF 2022, AF 2023), ESC (PE, Hypertension 2024), AABB 2023, BSH, IDSA, GOLD/BTS ועוד.
- **12 סבבי המעבדה, 10 קריאות הביפר ו-78 הבדיקות במעבדון** מקושרים למקורות; טווחי הייחוס נבדקו (תוקנו B12 ונויטרופילים).
- **מכניקות המשחק מבוססות מחקר בחינוך קליני**: מודל השיפוט הקליני של Tanner, רובריקת Lasater ו-NCSBN CJMM (ארבעת שלבי הקרב), סימולציות מטופל וירטואלי, משוב מיידי, כיול ביטחון, שליפה מרווחת ו-SBAR.
- הכל מרוכז ב-`js/evidence.js` ומוצג במסך **🔬 בסיס מחקרי** בתפריט (המכניקות + רשימת מקורות מלאה עם קישורים ל-PubMed ולאתרי הארגונים).

## עיצוב

ערכת צבעים בהירה (משמרת יום), יישור לימין בכל הממשק, וקרב בפריסה הפוכה המותאמת לקריאה מימין לשמאל: הבעיה הקלינית והלוחית שלה מימין למעלה, האח/ות והיציבות משמאל למטה.

## איך מריצים

- מקומית: `npx http-server game` (או כל שרת סטטי) ופתיחת `index.html`.
- GitHub Pages: מגישים את התיקייה `game/` — הכל סטטי, בלי build.
- PWA: `manifest.webmanifest` + `sw.js` (עובד אופליין אחרי טעינה ראשונה). לכל גרסה מעדכנים את `VERSION` ב-`sw.js`.

| בחירת ביטחון לפני תשובה | כיול: "בטוח/ה" פוגע חזק כשצודקים ועולה יותר כשטועים |
| יציבות המטופל = HP | טעות מחמירה את המטופל; 0 = קוד (מקבלים סיכום מלא ומנסים שוב) |
| סיכום אחרי כל אירוע | ארבע ההחלטות, ממצאים קריטיים, פנינה, סיכון, מסירת SBAR |
| 7 ביקורים גדולים (Gym leaders) | 60% מאירועי הפרק פותחים את חדר הישיבות; תג פותח את הפרק הבא |
| טל במעבדה | 12 סבבי מעבדה קריטיים + **מעבדון**: 78 בדיקות "לתפוס" בחידון זיהוי |
| מתמחים במסדרון / ביפר 📟 | חזרה מרווחת על אירועים שכבר נפתרו |
| שולה בקפיטריה | חנות: ☕ זמן · 🔦 חשיפת ממצאים · 📘 הסרת 2 מסיחים · 🛡️ בדיקה כפולה · 🤝 יציבות |
| ספה בחדר הצוות | סיום משמרת, משימות משמרת חדשות, רצף ימים 🔥 |
| מדף הספרים | פותח את גרסת הלימוד המלאה (`library/`) |
| מבואה, מכון שיקום, בית מרקחת, רחוב הקהילה | עולם פתוח בסגנון דור 3 — דלתות נפתחות לפי תגים, פריטים מוסתרים ✨ |
| 👥 צוות (Party) — 6 אנשי מקצוע לגיוס | פיזיותרפיה, ריפוי בעיסוק, קלינאות תקשורת, דיאטנית, רוקח, עו״ס — ⚡ יעילים נגד בעיות מהתחום (צוות רב-מקצועי, CGA) |
| ליאת בקבלה | "מרכז פוקימון": מנוחה לצוות (PP) |
| עשב גבוה ברחוב / מאמני קהילה | שאלות חזרה מהקהילה (יעל אחות הקהילה, משה המטפל) |
| ביקורי בית (לאה, אברהם) | סיור מפגעים בבית (STEADI, Cochrane 2023) · Teach-back עם מטפלת (AHRQ) |
| עידו, היריב | 3 קרבות לאורך המסע |
| מועצת המומחים (Elite Four) | 4 שופטים + יו״רית ברצף, הביטחון לא מתמלא בין הסבבים → היכל התהילה |

נוחות משחק (v1.6): התשובות בקרב מוצגות בשתי עמודות כך שכל השאלה נראית בלי גלילה והזירה נשארת גלויה; 🧭 חץ הכוונה מצביע ליעד הבא (אפשר לכבות בהגדרות); 🔥 רצף תשובות נכונות בניסיון ראשון נותן בונוס XP; פס היציבות משנה צבע (ירוק/צהוב/אדום) ובמצב נמוך המסך מהבהב באדום כמו אזעקת מוניטור.

שליטה: חיצים/WASD · Shift ריצה · Z/רווח/Enter פעולה · X/Esc חזרה · M תפריט. במגע: הקשה על משבצת = הליכה אליה (ואם זו מיטה או אדם — גם פנייה), החזקה = היגוי. בטלפון במצב אנכי המשחק מסתובב לרוחב, כמו בבופי מן.

נגישות: מהירות טקסט (כולל מיידי), גודל טקסט, ניגודיות גבוהה, הפחתת אפקטים (וגם `prefers-reduced-motion`), אזור `aria-live` לטקסט, ניווט מלא במקלדת.

## קבצים

```
game/
  index.html          מעטפת (HUD, מסך, תיבת הודעות, חלונות, פתיח)
  css/game.css        שפת הממשק של בופי מן v43–v57 + Mae splash
  js/content.js       התוכן הקליני (נוצר אוטומטית — לא לערוך ידנית)
  js/engine.js        קנבס 480×320 לוגי, טקסט RTL, קלט, סאונד ומוזיקה מסונתזים, אפקטים
  js/data.js          פרקים ותגים, סוגים קליניים, פריטים, מפות, דמויות
  js/evidence.js      שכבת הראיות: מקורות, נקודת הנחיה לכל אירוע, בסיס פדגוגי
  js/art.js           כל הגרפיקה מצוירת בקוד: אריחים, ריהוט, דמויות, מטופלים, יצורים, רקעים
  js/ui.js            HUD, תיבת דיאלוג/פקודות, חלונות, טוסטים
  js/battle.js        קרבות: אירוע, ביקור גדול, סבב מעבדה, ביפר/מתמחה
  js/world.js         המחלקה: תנועה, NPC, שדה ראייה של מתמחים, ביפר, הליכה בהקשה
  js/main.js          מצב, שמירה, התקדמות, דיאלוגים, תפריטים, פתיח, לולאה
  js/mae.js           פתיח Mae Studio (מתוך בופי מן)
  library/            Clinical Mastery v2.1 המקורי (ספריית ידע)
tools/extract-content.js   מחלץ מחדש את התוכן מ-library/index.html
```

עדכון תוכן: עורכים את הגרסה המלאה ב-`game/library/index.html` ומריצים `node tools/extract-content.js` — הסקריפט גם בודק שכל מפתח תשובה תקין.
