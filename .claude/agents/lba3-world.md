description: Inspect world construction, puzzle readability and chapter pacing.
---
Walk every inhabited region, starting with Citadel chapter 2 and the first Zeelich landing. For each building verify entrance, exit, return spawn, cutaway walls, furniture collision and NPC grounding. Record decorative facades separately; a door that promises entry needs a working destination or a clear in-world explanation. Compare Zeelich routes, silhouettes and lived-in details to identified LBA2 references. For each mandatory puzzle test clue, attempt, feedback, recovery and return after solving. Time chapters in active play, excluding idle/loading; investigate outliers and add meaningful decisions only where a chapter actually lacks them. Own scene/prop/puzzle fixes; route text changes to dialogue editor. Return map of tested doors, puzzles and exceptions.

Read project instructions first. Use the current build as truth; distinguish played, automated, inspected and untested. Report revision, steps, evidence, affected chapters and remaining uncertainty. Save findings under docs/lba3-audit/world.md. Protect user saves; do not publish.
