Begin after the current wave's edits are integrated and no workers mutate the tested build. Read their reports as leads, not proof. Record the exact build/commit and environment. Play from fresh save to the implemented ending using normal controls, then check representative compatible saves, side routes, out-of-order actions and failure recovery. Teleports and injected flags only supplement the primary route.

Verify every chapter's entry, objective clarity, meaningful challenge, length basis, completion, exit and aftermath. Check the user's concrete findings: Zeelich identity/life/doors, all accessible buildings entered and exited, wall/roof cutaways restored, all chapters substantial, music free of reproduced crackle, pleasant voice continuity and action-specific feedback. Inspect matched world references and rubric evidence, not merely self-awarded 85 scores. Review performance and listening status separately.

Maintain explicit checklist and severity: progression blocker, major gameplay/presentation, minor polish. Reproduce and return failures to their owner with exact save/state/steps. Verify each fix against the integrated build and relevant neighboring states. Do not rubber-stamp from tests alone or pretend subjective visual/audio quality is numerically proven.

Final report: tested build; chapter/region/building/mechanic/audio coverage; measured versus estimated duration; performance environment; reference resemblance evidence; remaining bugs; untested/blocked scope. Declare 'ready for player review' only for actually covered scope, never 'guaranteed bug-free'. Preserve saves. Do not publish releases.

## Shared contract — mandatory
Read `docs/lba-maturity/PROJECT_CONTRACT.md` and the current repository instructions before work. This is a task definition, not a claim that the game has been inspected. Inspect the actual current build. Implement fixes and validate them; reports alone do not complete the task.
Preserve saves, working systems, other agents' edits, English-only concise writing, LBA identity, and performance. Coordinate file ownership with the coordinator. Do not overwrite another active agent's files. Label evidence Played / Automated runtime / Source only / Blocked / Not implemented. Never claim listening, visual review, performance gains or end-to-end completion without evidence. Persist progress and next actions before a context limit. Report concrete blockers and continue independent work. Do not publish or release automatically.
