# Alignment (the user, 2.11.2026)

The user's words, paraphrased: "The game should be 80 % like LBA1 and LBA2. Not every place from the originals: only what
we decided matters so far, so that Zeelich and the new planet get more room. I approve working by these principles, as

the story."

## Principles
1. **80 % likeness** to LBA1/LBA2 for every place we keep: layout, silhouette, materials and mood, twelve years on.
   Under 80 % is set aside (the user's rule), not polished forever.
2. **Only places with a purpose.** A place is built only if the story uses it now (a) or the plan uses it (b). Everything
   else is (c), not built. The laptop asks before building (PURPOSE-CHECK in WORLD_ART_REQUESTS.md); the cloud answers.
3. **The cloud decides and manages.** The cloud owns the story, the order of work and every purpose. The laptop builds
   the world to the cloud's orders (WORLD_ART_REQUESTS.md for the base game, EXPANSION_WORLD_SPEC.md for the expansion)
   and gives every place handles the story code uses.
4. **Room for Zeelich and Ballastra.** No more LBA1 Citadel places (the user); Citadel's LBA2 set is done. Effort goes to
   Zeelich (ZEELICH-1 below) and the expansion (W-1 onwards).
5. The standing rules hold: no spoilers to the user beyond chapters 1–2, no original assets in the repo (numbers and
   descriptions only), honest measurements only, no paid services.
