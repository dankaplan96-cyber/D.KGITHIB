# P81 — the campaign pass and the revisits (dialogue editor, 20.11.2026)

Brief: `P81-BRIEF.md` ("then every reachable chapter and the epilogue" and "Revisits"), as the coordinator scoped it on
20.11: the whole-campaign pass and the return visits, with timing (subtitles, voice intentions, skip). Base
`ccr-c1c2c4b9-dep6ed` at `c2eeab2f`. This pass builds on DIALOGUE-EDIT (15.11) and DIALOGUE-2 (19.11), which read every
chapter line by line; it does not redo them. It looks for the brief's three aims: **who is speaking**, **what matters
(essential clues on demand, the right line in the right state)**, and **places changing after Twinsen helps**.

**Not in this pass (owned elsewhere, to come after their merges):** P81 scene 1 (Mill Lane's radio and Vesk's decision:
`text/answer.js`, `story/answer.js`) and scene 2 (the Zeelich confrontation from `c2_vesk_1`) go with REVIEW-TASKS task 3;
scene 3 (Ballastra's customs) and everything Ballastra, the network (chapter 14) and the epilogue wait for EXP-3
(chapters 12–13). Scene 4 (the family opening) was done by TUT-MYSTERY and is not touched here.

**Evidence labels.** *Automated runtime*: a headless Chromium test drove the game (this worktree served on
127.0.0.1:8791, SwiftShader, a shared machine). *Source only*: the exchange was read with the code that plays it (its
conditions and order). Nobody played or listened. The LBA1/LBA2 originals are not on this machine; no original line was
read or quoted.

**Rules kept.** String IDs, speakers' names, placeholders and flags unchanged; new keys only where a state had no line;
every changed or new English line has its Hebrew (`text/he/`, then `node tools/he-bundle.mjs`); each changed or new
spoken line has a `voicemeta.js` entry (one intention per sentence: it also drives the face); `node tests/dialogue-check.mjs`
PASS. No new shipped file (the new test and its two captures are not shipped). Old saves: nothing new is saved; every
change reads flags that already exist.
