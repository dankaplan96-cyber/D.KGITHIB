The user, 31.10.2026: LBA3's principle is that twelve years have passed since LBA2, so it is natural that the world has changed. When comparing with the original LBA1/LBA2 files, a difference is not a bug in itself.

**Why:** the user wants the original's charm and quality, not a copy. Change is part of the story (docs/TWELVE_YEARS.md).

**How to apply:**
- **Use the originals for craft:** proportions, silhouettes, readable shapes, palette relationships, purposeful placement.
- **Not for positions or contents:** never write a request that only says "move or rebuild it to match the original".
- **What earns a request:** a difference that hurts the look (thin roofs, odd scale, merging colours, purposeless placement), or one that loses LBA's charm with no twelve-years reason.
- **Missing, moved or changed things** may be intentional (repairs, new uses). Check docs/TWELVE_YEARS.md before calling one a problem.

Related: [[lba3-world-art-role]]

**The target is 80 %, as the user told the cloud session (docs/WORLD_SIMILARITY.md; confirmed 31.10.2026, after a brief mention of 85): about 80 % similar to the original rather than 100 %, because twelve years passed and things changed. The doc scores each area's similarity to the original. Hamalayi is the exception: it is our own larger region with a few recognisable LBA1 spots. A request never aims at 100 % likeness. If an area is already at about 80 %, only problems of look or charm count, not likeness.

**Update 7.11.2026:** the user's Maturity Agent Pack (see [[lba3-maturity-pack]]) sets the target at **85/100 per revisited place**. It is a human-reviewed rubric, not a pixel match: geography 25, landmarks 20, architecture 20, palette 15, vegetation 10, inhabitants 10. Missing evidence means unverified, and there is no averaging into one global score. Until the cloud says otherwise, the twelve-years principle still holds, inside that rubric.
