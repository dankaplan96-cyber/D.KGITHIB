# HerzoSign – החתימה הדיגיטלית של הרצוג

**פחות ניירת. יותר זמן לטיפול.**

מערכת אינטרנט שמעבירה את כל הטפסים והחתימות של בית החולים לממוחשב: טפסי כוח אדם, חוברות הדרכה וקליטה ואישורי קריאת נהלים. כל טופס נחתם בטלפון או במחשב ועובר אוטומטית לאישור הגורם הנכון.

## מה יש במערכת

| עבור | יכולות |
|---|---|
| **כל עובד/ת** | מילוי טופס וחתימה באצבע או בהקלדה · צירוף אישור מחלה מהמצלמה · מעקב אחרי מיקום הטופס במסלול האישור · משימות לחתימה (נהלים וחוברות) · תיקון והגשה מחדש |
| **מנהל/ת מחלקה** | דשבורד עם "ממתינים לטיפולי" · אישור וחתימה / החזרה לתיקון / דחייה / **העברה לגורם אחר** / **אישור והעברה** · כל טפסי המחלקה · שיוך נהלים לצוות ומעקב מי חתם |
| **משאבי אנוש / הדרכה** | תור משותף לטיפול · בונה תבניות טפסים (ללא קוד) עם גרסאות · ניהול משתמשים · מעקב היענות |
| **מנהל/ת מערכת** | מחלקות ומנהלים · כל ההרשאות |

**טפסים מוכנים (תוכן לדוגמה):** בקשת חופשה, הודעה על מחלה, החלפת משמרת, שעות נוספות, עדכון פרטים, הצהרת סודיות, בקשה להשתלמות, חוברות קליטה לאחות חדשה / סטודנט / כוח עזר, ואישורי קריאת נהלים (היגיינת ידיים, מניעת נפילות, אירוע חריג).

**אבטחה וראיה:** סיסמאות מוצפנות (scrypt), עוגיית סשן HttpOnly, הגבלת ניסיונות התחברות, הגנת CSRF, CSP, הרשאות לפי תפקיד, יומן ביקורת מלא (כולל צפיות), וטביעת אצבע SHA-256 שמזהה שינוי בתוכן אחרי החתימה.

**נגישות:** עברית RTL, ניווט מלא במקלדת, תמיכה בקוראי מסך, חתימה מוקלדת כחלופה, הגדלת טקסט, ניגודיות גבוהה ומצב כהה.

רקע ומחקר: [docs/research.md](docs/research.md)

## הרצה מקומית

דרוש Node.js 22.13 ומעלה.

```bash
cd herzosign
npm install
npm start            # http://localhost:3000
npm test             # בדיקות אוטומטיות של כל מסלולי האישור
npm run reset-db     # איפוס מסד הנתונים לנתוני הדגמה
```

משתמשי הדגמה (סיסמה `Herzog2026`):

| מס׳ עובד | תפקיד |
|---|---|
| 1000 | מנהל/ת מערכת |
| 2001 | אחות אחראית – גריאטריה א׳ |
| 2002 | אח אחראי – שיקום |
| 3001 | משאבי אנוש |
| 4001 | אחות אחראית הדרכה |
| 5001 / 5002 / 5003 | אחות / סטודנט / כוח עזר (גריאטריה א׳) |

## פריסה לאינטרנט (גישה מכל מקום)

המערכת היא שרת Node אחד עם קובץ SQLite, ואפשר להריץ אותה בכל שרת או ענן שתומך ב-Docker:

```bash
docker build -t herzosign .
docker run -d -p 3000:3000 -v herzosign-data:/data \
  -e SEED_DEMO=0 -e ADMIN_PASSWORD='<סיסמה-חזקה>' -e TRUST_PROXY=1 herzosign
```

| משתנה | משמעות |
|---|---|
| `SEED_DEMO=0` | בלי משתמשי הדגמה. נוצר רק מנהל מערכת (מס׳ 1000) עם `ADMIN_PASSWORD`, שיידרש להחליף סיסמה בכניסה הראשונה |
| `DB_PATH` | מיקום קובץ מסד הנתונים (ברירת מחדל ב-Docker: `/data/herzosign.db`) |
| `TRUST_PROXY=1` | כשהמערכת רצה מאחורי HTTPS proxy / load balancer |
| `SESSION_HOURS` | משך החיבור (ברירת מחדל: 12 שעות) |

> ⚠️ לפני שימוש עם נתונים אמיתיים: HTTPS חובה, גיבוי יומי של `/data`, ותיאום עם אבטחת המידע של בית החולים. ייתכן שיידרש אירוח בתשתית הפנימית. פרטים ב-[docs/research.md](docs/research.md).
